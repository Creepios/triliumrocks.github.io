Trilium Rocks

This repository contains the frontend assets and templates used by the original trilium.rocks website.

The original site content pages are authored in a private Trilium instance and are not stored in this repository, so this GitHub Pages deployment cannot reproduce the full historical site content by itself.

What is available here

  • Maintained CSS/JavaScript source used by the Trilium share templates
  • EJS share templates from src/templates
  • Project context and contribution details in the repository README
